# Atulya's Portfolio

A personal website that is both a portfolio and a weekly log of what I read, paint, learn, watch and think.

See [PROJECT.md](./PROJECT.md) for goals, design direction and milestones, and [docs/recaps](./docs/recaps) for what each milestone built.

## Run it locally

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # unit tests (Vitest)
npm run lint
npm run build    # production build
```

## Stack

Next.js (App Router) + TypeScript, Tailwind CSS, Vitest. Hosted on Vercel.
